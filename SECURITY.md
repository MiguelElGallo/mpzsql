# Security Policy

## Supported Versions

This project currently supports the latest release on the default branch.

## Reporting a Vulnerability

Please report security issues privately by email:

- `60221874+MiguelElGallo@users.noreply.github.com`

Include:

- a clear description of the issue
- reproduction steps or proof-of-concept
- impact assessment
- suggested mitigation (if available)

Do not create public GitHub issues for vulnerabilities.

## Response Expectations

- Initial acknowledgment target: within 5 business days
- Remediation timeline depends on severity and complexity
- Public disclosure happens after a fix is available (or a mitigation is documented)
