# Contributing to mpzsql

First off, thank you for considering contributing to mpzsql. It's people like you that make mpzsql such a great tool.

## Where do I go from here?

If you've noticed a bug or have a question, [search the issue tracker](https://github.com/MiguelElGallo/mpzsql/issues) to see if someone else has already created a ticket. If not, go ahead and [create a new one](https://github.com/MiguelElGallo/mpzsql/issues/new/choose)!

## Fork & create a branch

If you're going to contribute code, please fork the repository and create a new branch. This is where you'll do all of your work. When you're ready to submit your changes, you can create a pull request.

## Code Style

Please follow the coding style of the project. We use `black` for code formatting and `ruff` for linting. You can use `pre-commit` to automatically run these checks before you commit your code.

## Testing

Please make sure that your changes include tests. We use `pytest` for testing. You can run the tests by running `pytest` in the root of the repository.

## Documentation

If you're adding a new feature, please make sure to update the documentation as well.

## Submitting a pull request

When you're ready to submit your changes, create a pull request. Please make sure to include a detailed description of your changes.

Thank you for your contribution!
